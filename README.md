# Bella Chen — Product Portfolio

Static GitHub Pages portfolio.

- `index.html`: portfolio homepage
- `permission/case-study.html`: enterprise permission case study
- `permission/demo.html`: interactive permission demo
- `permission/docs/product-specification.md`: product specification

## Publish
Upload the contents of this folder to the **root** of your GitHub repository. Under **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`, and Save.
