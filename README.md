## English

Hi, I'm Bella — a **Product Manager in FinTech & platforms** with 10+ years across trading systems, API management, financial data and global mobile apps. Building is half of it. The other half is asking why: how a product works, how it makes money, and who it's really for.

**What I work on**
- **Trading & FinTech** — trading platforms, order flows, FIX API governance, trading configuration and financial operations
- **Enterprise platforms** — permissions / RBAC, admin tools, back-office workflows and business rules
- **Consumer & data products** — mobile experiences, community features, financial data tools and analytics

I use AI (Claude, ChatGPT) to move from idea to a testable prototype faster; problem framing, product decisions and accuracy stay with me. Everything public here is rebuilt with fictional data — no confidential company or customer data.

## 中文

你好，我是 Bella，十年以上產品經驗，橫跨交易系統、企業平台與 C 端 App。上線前，我寫 PRD、對齊各團隊；上線後，我看數據、追蹤使用者實際怎麼用，再決定下一步。想法還早時，我會先用 AI 做出能點的原型。

**專長領域**
- **交易系統與金融科技**：交易平台、訂單流程、FIX API 管理、交易設定與金融營運
- **企業級平台**：權限管理／RBAC、管理工具、後台流程與商業規則
- **消費性產品與資料應用**：行動體驗、社群功能、金融資料工具與數據分析

我用 AI（Claude、ChatGPT）加快從想法到可測試原型的過程；問題定義、產品決策與正確性仍由我負責。網站上公開的內容皆以虛構資料重建，不含任何公司或客戶的機密資料。
