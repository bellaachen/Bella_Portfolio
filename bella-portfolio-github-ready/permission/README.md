# Enterprise Permission Management — Portfolio Case Study

A reconstructed, interactive portfolio project documenting the product management work behind a production-launched permission management feature for a financial trading Back Office.

## Open locally

- `case-study.html` — public-facing English case study
- `demo.html` — interactive UI reconstruction
- `docs/product-specification.md` — core business rules, acceptance criteria, and open questions

You can open `case-study.html` directly in a browser. For local development, serve this folder with any static file server (e.g. `python -m http.server 8000`) and visit `http://localhost:8000/case-study.html`.

## Portfolio focus

- Role-based access control (RBAC) and individual permission customization
- Hierarchical permission tree and indeterminate selection
- Cross-functional product ownership from requirements through production launch
- Explicit separation between verified product behavior and reconstructed demo assumptions

## Confidentiality

All names, account data, and sample role configurations in the demo are fictional. This project is a portfolio reconstruction, not production source code or a replica of internal records. No company branding is included.

## Publishing

Host the entire folder on a static website (GitHub Pages, Netlify, Vercel, or your portfolio host). Keep `case-study.html`, `demo.html`, `assets/`, and `docs/` together so relative links work. Do not present demo behavior as a verified production rule where the documentation marks it as unverified.
